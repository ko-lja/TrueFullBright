# TrueFullBright

Actually working clientside fullbright mod for 1.7.10.

Also works with [Darkerer](https://github.com/GTNewHorizons/Darkerer)!

## Features

- Full brightness everywhere, day or night, underground or fully enclosed
- Removes smooth lighting corner shadows (ambient occlusion) while active
- Stops the fog from turning black at low Y levels
- Removes the dark vignette that grows in dark areas
